# Calculator Project

This project is a simple calculator built using **HTML**, **CSS**, and **JavaScript**. It performs basic arithmetic operations like addition, subtraction, multiplication, and division, with additional functionality for handling percentages, clearing the display, and using a backspace.

## Features

- **Basic Operations**: Supports addition, subtraction, multiplication, and division.
- **Clear Functionality**: The `AC` button clears the current input.
- **Backspace**: The backspace button (`&#9003;`) removes the last character in the display.
- **Percentage**: The `%` button calculates percentages.
- **Chaining Operations**: Allows users to chain operations together for more complex calculations.
- **Responsive**: The layout adjusts to different screen sizes and devices.

## Files

1. **index.html**: The main HTML structure of the calculator. Contains the buttons and input field for displaying the result.
2. **style.css**: The stylesheet used to style the calculator buttons and layout.
3. **practice.js**: Contains the JavaScript logic for the calculator, handling input display, operations, clearing, and backspacing.

## How It Works

- The user interacts with the calculator by pressing the on-screen buttons.
- Numbers and operators are displayed on the input field.
- When the `=` button is clicked, the calculation is performed using the `calculate()` function.
- The `AC` button clears the display, while the backspace button removes the last character.
- The result is shown in the same input field.

## Usage

1. Clone the repository to your local machine:

   ```bash
   git clone https://github.com/rishabpradhan/Frontend/tree/master/front/cookie_consent.git
   ```

2. Open the project folder and run the `index.html` file in your browser:
   ```bash
   open index.html
   ```
